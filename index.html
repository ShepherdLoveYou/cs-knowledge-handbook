计算机知识手册

把一次真实的运维会话——刷机、装旁路由、去广告、修 WiFi、给 Windows 提权、跟 Secure Boot 打交道——和计算机专业的核心理论(408:计算机网络 / 操作系统 / 组成原理 / 数据结构与算法),以及信号与系统、密码学、运维工程这几条拓展线,打通成一套图文并茂、可离线阅读的自包含手册。每章都有真实的踩坑现场、能跟着算一遍的例子,以及指回其它章节的一条线。

全部 16 章自包含、可离线双击打开、支持打印;每章开头有本章目录,结尾有交叉引用与 MCP 联网取证来源列表。右上角 🌓 可随时切换亮 / 暗主题,不受系统设置限制。

Part I 实战复盘

这九章贴着本次会话的真实操作走:一台"过期"的 Chromebox 怎么被刷成裸机、怎么装成旁路由、怎么接管 DNS、WiFi 信道与功率怎么算、文件怎么跨平台搬、Windows 后台在忙什么、固件那几道锁到底锁住了谁。

01
从 Chromebox 到 UEFI:刷机与固件
一台"过期"的 Chromebox 靠写保护螺丝、coreboot、UEFI Full ROM 变身普通 x86 裸机——这台机器后面会变成旁路由。
02
软路由与旁路由
网关、子网、DHCP、NAT 四块地基,拆开"只接管 DNS、不当网关"这个旁路由核心技巧。
03
DNS 与去广告
从根域到权威服务器的分层解析,dnsmasq 接力 AdGuard Home,外加 DoH/DNSSEC 与 IPv6 泄漏两个真实的坑。
04
WiFi 与射频
2.4/5GHz 频段与信道、802.11 世代演进,实测 Intel AX201 网卡为什么怎么也开不出 5GHz 热点。
05 🎮 互动
dBm · 分贝 · 信号强度
分贝与 dBm 的对数语言,从 22dBm 发射一路算到 −31dBm 接收,拆解路径损耗与 EIRP。
06
文件共享与跨平台互传
SMB/Samba、苹果专有 AWDL、开源 LocalSend/PairDrop——三种"把文件搬到另一台设备"的不同答案。
07
文件系统
inode、日志、扩展属性三大机制,ext4/exFAT/NTFS 怎么选、go-bag U 盘为什么必须 exFAT。
08
Windows 系统管理与提权
服务启动类型、UAC 双令牌、powercfg 限速表,外加一次真正揪出吃 CPU 进程的实战排查。
09
固件安全与内核驱动
Secure Boot → 驱动签名 → HVCI → SMM → BitLocker 五道门,收束到五个特权环这张统一坐标系。

Part II 计算机核心(408 拓展)

把 Part I 里散落的实战现象,归位进计算机专业最核心的四门课——这也是大多数学校 408 统考的范围:计算机网络、操作系统、计算机组成、数据结构与算法。

10 🎮 互动
计算机网络体系(408)
五层协议栈把旁路由、DNS、WiFi、SMB 的实战串成一张地图,外加三次握手与"分层排障法"。
11
操作系统(408)
进程/线程调度、虚拟内存与分页、VFS、系统调用与中断——操作系统这位"总管"要做的四件事。
12
计算机组成原理 + 数电基础(408)
冯诺依曼架构、逻辑门与流水线、存储层次与总线,拆开 Turbo Boost 与散热降频的完整因果链。
13 🎮 互动
数据结构与算法
Big-O、线性表/树/图/哈希表与排序——前面几章"秒回"背后,数据怎么摆、步骤怎么走。

Part III 深化拓展

再往下、往外拓展三步:信号与系统补上 WiFi/dBm 背后的数学,密码学与网络安全补上签名、加密、证书的底层机制,运维与自托管工程把前面十五章的手动操作升级成一套真正的工程化基础设施。

14
信号与系统
LTI 系统、傅里叶、采样定理、QAM 与 OFDM——从 22dBm 一路算到香农极限给出的 Mbit/s 上限。
15
密码学与网络安全
对称/非对称加密、哈希、数字签名、PKI 与 TLS 1.3 握手,手算一遍教科书版 RSA。
16
运维与自托管工程
容器 namespace/cgroup、反向代理、监控三支柱、3-2-1 备份与 CI/CD——把整台盒子升级成工程。
