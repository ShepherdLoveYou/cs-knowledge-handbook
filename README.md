# 计算机知识手册 · Computer Knowledge Handbook

一套图文精美、**自包含**的计算机知识教程 —— 从一次真实的 homelab 折腾出发(Chromebox 刷机 → 软路由旁路由 → WiFi/dBm → 文件共享 → Windows 运维 → 固件安全),再往下打通 **计算机 408 核心 + 信号与系统 + 密码学 + 运维工程**。

🌐 **在线阅读**:https://shepherdloveyou.github.io/cs-knowledge-handbook/

## 特点

- **16 章 + 导航页**,每章一个自包含 HTML(内联 CSS + 手绘 SVG 图),可离线、可打印、亮暗自适应
- 内容经**联网取证**(官方文档 / RFC / 标准 / 经典教材 / 维基),每章页脚列出来源
- **「先为什么、后怎么做」**的渐进式讲法 + 彩色标注框(实战锚点 / 原理 / 类比 / 场景 / 深挖 / 避坑 / 要点)
- 抽象概念一律配**生活类比 + 真实场景**:dB 与 dBm 用登山的"高度差 vs 海拔"讲、协议封装用拆包裹讲、Big-O 用搬家讲、哈希表用图书馆找书讲
- 每章至少一个**跟得住的 worked example**,数字来自真实设备实测(如 AP 发射 22dBm → 笔记本收到 −31dBm,一路算到路径损耗 53dB)
- 一张**「实战 ↔ 理论」关系地图**把 16 章连成体系,外加三条阅读路径(零基础 / 想学网络 / 想学底层)

## 可以动手玩的章节

第 **05 dBm** / **10 网络** / **13 数据结构** 三章,关键概念配了可交互的图,**就嵌在讲那个概念的段落里**,拖完接着往下读:

| 章 | 控件 | 拖一拖能看到什么 |
|---|---|---|
| 05 | 信号衰减曲线(JSXGraph) | 发射功率只把曲线整体平移;频率 2.4→5.8GHz 整条线下沉约 7.7dB;距离每翻倍固定跌 6dB |
| 10 | TCP 三次握手动画(p5.js) | 单步走 SYN → SYN,ACK → ACK,看两端状态机怎么变到 ESTABLISHED |
| 10 | CIDR 子网计算器 | 前缀长度与可用主机数的关系,以及 `/31`(RFC 3021)、`/32` 两个特例 |
| 13 | 排序可视化(p5.js) | 四种算法的比较/交换次数实时对比 —— 冒泡和选择比较次数固定,只有插入排序会看数据形状提前收手 |

> **没有测验、不打分。** 这里的目标是学会概念,不是通过考试 —— 所以没有习题册和闪卡,知识点都写在正文里。右下角只有一个无评判的阅读进度(已读 N/16 章)。

## 本地查看

Clone 后直接双击 `index.html` 即可,**无需任何依赖或构建**。

交互控件用的 [p5.js](https://p5js.org/) 和 [JSXGraph](https://jsxgraph.org/) 两个开源库已经**本地化到 `assets/vendor/`**,全站零 CDN、零外部请求 —— 断网也能跑。

```
├── index.html          # 导航页(卡片墙 + 关系地图 + 阅读路径)
├── chapters/           # 01..16 章,每章一个自包含 HTML
└── assets/vendor/      # p5.min.js / jsxgraphcore.js / jsxgraph.css
```
